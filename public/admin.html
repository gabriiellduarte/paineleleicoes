Importar do TSE

Busca direto no TSE os candidatos dos cinco cargos (presidente, governador, senador, deputado federal e estadual) e todas as seções, locais de votação, endereços, coordenadas e eleitores aptos do município. Cada importação adiciona uma cidade: para ter várias, importe uma de cada vez (as já cadastradas são mantidas; reimportar a mesma só atualiza). Dados de exemplo são apagados na primeira importação. Seções agregadas entram junto da seção principal, que é a que tem boletim próprio.

Endereço dos links dos chefes

Os links dos chefes de local usam este endereço. Se ficar em branco, o sistema usa o endereço da rede local (só funciona no mesmo Wi-Fi). Para chefes em outros lugares, o computador precisa estar acessível pela internet: cole aqui o endereço público (por exemplo, o que um túnel como o Cloudflare Tunnel gera). Depois, gere os links de novo.
